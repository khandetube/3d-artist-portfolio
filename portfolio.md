# Technical Portfolio — Real-Time 3D Asset Pipeline

This repository demonstrates self-initiated technical work around production-oriented 3D asset delivery. It is not presented as previous client work.

## Core areas
- Blender-based asset preparation
- glTF / GLB delivery
- PBR materials and UV verification
- Geometry and shading checks
- Transforms, origins, pivots and hierarchy
- Python automation and repeatable validation
- Browser/runtime-oriented delivery

## Delivery checklist
- Geometry reviewed
- Normals and smoothing reviewed
- UVs verified
- PBR inputs verified
- Transforms and pivots checked
- Hierarchy and naming checked
- glTF/GLB export completed
- Export structurally validated
- Browser/runtime test completed

Only work actually present in this repository should be treated as demonstrated work.
